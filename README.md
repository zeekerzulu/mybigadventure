# mybigadventure.com

JD's 2004 six-month loop of the lower 48 (July 8, 2004 – January 2005): daily travel log with photos, plus offshoot sections (Parks, Sites, Biking, Hiking, Communities, Memorials, Monuments, Museums, States, Statistics). Custom PHP, served from A2 Hosting; developed locally under MAMP at `/Applications/MAMP/htdocs/mybigadventure/`.

- `Travel_Log/<YYYYMMDD>/page_N.php` — the daily entries (`Templates/` = blank stubs)
- `Journal/` — weekly synopsis pages
- `Pics/Daily/<YYYYMMDD>/Small/` — thumbnails (tracked); the full-size originals are NOT in this repo
- `dbconnector.php` — gitignored; see `dbconnector.example.php`

Project notes and to-dos: `~/projects/mybigadventure/` (private claude-notes repo).
